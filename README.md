## Getting started

### 1. Prerequisites

Install [ROS 2 Jazzy](https://docs.ros.org/en/jazzy/Installation.html) (desktop version), then install the extra tools these packages use:

```bash
sudo apt install python3-colcon-common-extensions \
                 ros-jazzy-xacro \
                 ros-jazzy-robot-state-publisher \
                 ros-jazzy-joint-state-publisher-gui \
                 ros-jazzy-rviz2 \
                 ros-jazzy-ros-gz
```

`ros-jazzy-ros-gz` installs Gazebo Harmonic and the ROS–Gazebo bridge packages (`ros_gz_sim`, `ros_gz_bridge`).

### 2. Clone and build

```bash
git clone <this-repo-url> arduinobot_ws
cd arduinobot_ws
source /opt/ros/jazzy/setup.bash
rosdep install --from-paths src --ignore-src -y   # optional: installs any missing dependencies
colcon build
source install/setup.bash
```

> Run `source install/setup.bash` in **every new terminal** before you use these packages.

### 3. Try it out

```bash
# Terminal 1: publish messages on /chatter
ros2 run arduinobot_py_examples simple_publisher

# Terminal 2: receive them
ros2 run arduinobot_py_examples simple_subscriber

# Show the robot arm in RViz, with sliders to move each joint
ros2 launch arduinobot_description display.launch.py

# Simulate the robot in Gazebo
ros2 launch arduinobot_description gazebo.launch.py
```

Each package README has more details and examples.

## Useful commands

```bash
ros2 node list                      # running nodes
ros2 topic list                     # active topics
ros2 topic echo /chatter            # print messages on a topic
ros2 topic info /chatter -v         # publishers/subscribers + QoS
ros2 param list                     # parameters of all nodes
ros2 run rqt_graph rqt_graph        # visual graph of nodes and topics
ros2 run tf2_tools view_frames      # PDF of the robot's TF tree
```
